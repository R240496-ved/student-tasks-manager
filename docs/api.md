# Planned REST API

Base path: `/tasks`

| Method | Endpoint | Purpose |
|---|---|---|
| `GET` | `/tasks` | List tasks |
| `GET` | `/tasks/{id}` | Get one task by ID |
| `POST` | `/tasks` | Create a task |
| `PUT` | `/tasks/{id}` | Update a task by ID |
| `DELETE` | `/tasks/{id}` | Delete a task by ID |

## Planned Task object

- `id`
- `title`
- `description`
- `status`
- `priority`
- `deadline`
